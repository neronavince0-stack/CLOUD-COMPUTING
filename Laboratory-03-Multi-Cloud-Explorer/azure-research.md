
# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, networking, databases, security, artificial intelligence, and application development. Azure allows organizations to run applications and infrastructure using Microsoft's cloud environment.

## Global Infrastructure

Azure operates a global infrastructure consisting of geographic regions and data centers. Azure Regions contain one or more data centers and allow organizations to deploy applications in locations close to their users. This global infrastructure helps improve application availability, performance, and reliability.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Administrators can manage virtual machines, databases, storage, networking, security, and other cloud services through the portal.

## Four Core Services

1. **Azure Virtual Machines** – Provides virtual machines for running applications and workloads.
2. **Azure Blob Storage** – Provides scalable object storage for unstructured data such as documents, images, and backups.
3. **Azure Virtual Network** – Provides private networking for Azure resources.
4. **Microsoft Entra ID** – Provides identity and access management for users and applications.

## Three Advantages

1. **Microsoft Integration** – Azure works closely with Microsoft products such as Windows Server and Microsoft 365.
2. **Enterprise Support** – Azure provides services designed for organizations with large and complex IT environments.
3. **Hybrid Cloud Capabilities** – Azure supports integration between on-premises infrastructure and cloud services.

## Typical Enterprise Use Cases

Azure is commonly used by enterprises for hosting applications, running Windows Server workloads, managing databases, storing business information, and implementing hybrid cloud environments. Organizations can also use Azure for Microsoft 365 integration, artificial intelligence, analytics, and application development.
