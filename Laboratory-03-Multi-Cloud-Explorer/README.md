
# Mission 3 – Multi-Cloud Explorer

## Linux Server Investigation

### Operating System

The Linux server operating system was identified using the `cat /etc/os-release` command.

### CPU Information

The CPU information was identified using the `lscpu` command.

### Memory

The server memory information was identified using the `free -h` command.

### Disk Space

The available disk space was identified using the `df -h` command.

## Cloud Migration

If this Linux server were migrated to the cloud, it could be hosted using virtual machine services from all three major cloud providers:

* **AWS:** Amazon EC2
* **Microsoft Azure:** Azure Virtual Machines
* **Google Cloud Platform:** Compute Engine

These services provide virtual computing environments where Linux-based workloads can be deployed and managed.
