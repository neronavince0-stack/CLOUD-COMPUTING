
# Client Recommendations

## Client A – Startup Company

### Recommended Platform

**AWS**

### Recommendation

AWS is a suitable choice for the startup because it provides a wide range of services and allows resources to scale as the application grows. The company can begin with a smaller infrastructure to control costs and increase resources when demand increases. AWS also provides many services that can support mobile applications and backend systems.

### Recommended Services

1. **Amazon EC2** – For running application servers.
2. **Amazon S3** – For storing images, files, and application data.
3. **Amazon RDS** – For managing the application's relational database.

---

## Client B – University

### Recommended Platform

**Microsoft Azure**

### Recommendation

Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making cloud migration easier to manage. The university can gradually move selected services to Azure while maintaining compatibility with its existing environment.

### Recommended Services

1. **Azure Virtual Machines** – For running Windows Server workloads.
2. **Azure Blob Storage** – For storing documents and files.
3. **Microsoft Entra ID** – For identity and access management.

---

## Client C – AI Research Company

### Recommended Platform

**Google Cloud Platform**

### Recommendation

Google Cloud Platform is a strong choice for an AI research company because it provides services designed for artificial intelligence, machine learning, and high-performance computing. The company can use Google Cloud's AI and machine learning tools to develop and train models. Google Cloud also provides scalable computing resources that can support demanding research workloads.

### Recommended Services

1. **Compute Engine** – For high-performance computing workloads.
2. **Google Cloud GPUs/TPUs** – For accelerating AI and machine learning workloads.
3. **Vertex AI** – For developing and deploying machine learning applications.

---

## Client D – Global E-Commerce Company

### Recommended Platform

**AWS**

### Recommendation

AWS is a suitable choice for a global e-commerce company because it provides a large global infrastructure and scalable cloud services. The company can distribute applications across multiple locations and automatically increase resources when customer traffic increases. AWS also provides services for storage, databases, networking, and application scaling.

### Recommended Services

1. **Amazon EC2** – For application servers.
2. **Amazon S3** – For storing product images and other files.
3. **Elastic Load Balancing** – For distributing traffic across application servers.
4. **Amazon EC2 Auto Scaling** – For automatically adjusting computing capacity.
