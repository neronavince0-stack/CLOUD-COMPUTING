
# Mission 3 Reflection

The cloud platform that impressed me the most was Amazon Web Services (AWS) because of its wide range of services and flexibility. AWS provides many solutions for computing, storage, networking, databases, security, and other cloud requirements. I also found its scalability useful because organizations can adjust their resources depending on their workload.

AWS, Microsoft Azure, and Google Cloud Platform have many similarities. All three provide virtual machines, object storage, networking, identity management, databases, and other cloud services. They also use global infrastructure consisting of geographic locations where organizations can deploy their applications and services.

Business requirements have an important influence on cloud platform selection. Organizations need to consider their budget, existing technologies, performance requirements, security needs, scalability, and the type of applications they will run. For example, an organization that already uses Microsoft technologies may benefit more from Azure, while an AI-focused company may prefer Google Cloud.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The best choice depends on the specific requirements and goals of the client. I learned how to compare cloud services and match technical capabilities with business needs.

My GitHub Cloud Computing Portfolio improved because I added a complete multi-cloud investigation containing research, comparisons, recommendations, a decision matrix, and Linux server investigation results. This makes the portfolio more organized and demonstrates my understanding of different cloud platforms and their services.
