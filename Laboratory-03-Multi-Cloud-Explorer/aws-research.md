
# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of cloud services that organizations can use for computing, storage, databases, networking, security, and other IT requirements. AWS allows businesses to access computing resources over the internet without needing to maintain all physical infrastructure themselves.

## Global Infrastructure

AWS operates a large global cloud infrastructure consisting of Regions and Availability Zones. AWS Regions are separate geographic areas, while Availability Zones are isolated locations within a Region. This infrastructure allows organizations to deploy applications closer to their users and improve availability and reliability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create and configure resources, monitor services, manage security settings, and control their cloud infrastructure through the console.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers that can be used to run applications and workloads.
2. **Amazon S3** – Provides scalable object storage for files, documents, images, backups, and other data.
3. **Amazon VPC** – Allows users to create and manage virtual networks in AWS.
4. **AWS IAM** – Provides identity and access management for controlling access to AWS resources.

## Three Advantages

1. **Wide Range of Services** – AWS provides many services covering computing, storage, databases, networking, security, analytics, and artificial intelligence.
2. **Scalability** – AWS allows organizations to increase or decrease resources according to their workload requirements.
3. **Global Infrastructure** – AWS has a large worldwide infrastructure that allows applications to be deployed in different geographic locations.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for hosting websites and applications, storing business data, running databases, creating backup systems, and deploying scalable applications. Organizations can also use AWS for data analytics, artificial intelligence, disaster recovery, and other enterprise workloads.
