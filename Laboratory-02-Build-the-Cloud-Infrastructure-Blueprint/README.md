# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

In this laboratory activity, I investigated a Linux cloud environment using KillerCoda. I identified the main cloud infrastructure components and compared the services offered by AWS, Microsoft Azure, and Google Cloud Platform.

## Objectives

* Understand the main components of cloud infrastructure.
* Investigate the resources available in a Linux environment.
* Identify compute, storage, networking, and operating system resources.
* Compare the basic services of AWS, Azure, and Google Cloud.
* Create a simple cloud infrastructure diagram.
* Practice documenting technical information using Markdown.

## Cloud Infrastructure Components

The main components identified in the Linux environment were:

* **Compute** – CPU and CPU cores used to process tasks.
* **Storage** – Disk space and file systems used to store data.
* **Networking** – Network interfaces and IP address used for communication.
* **Operating System** – Linux, which manages the system resources and allows applications to run.

## Tools Used

* KillerCoda
* GitHub
* Linux Terminal
* Web Browser
* Markdown
* Draw.io / Diagramming Tool

## Linux Commands Executed

The following commands were used to investigate the Linux environment:

```bash
cat /etc/os-release
uname -r
lscpu
nproc
free -h
lsblk
df -h
hostname
hostname -I
ip addr
```

These commands were used to check the operating system, kernel, CPU, memory, storage, file systems, hostname, and network information.

## Skills Learned

During this laboratory activity, I learned how to inspect a Linux server and identify its basic infrastructure resources. I also learned how to compare cloud services, create a simple infrastructure diagram, and organize technical documentation in a GitHub repository.
