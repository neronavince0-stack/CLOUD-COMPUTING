
# Cloud Provider Comparison

## Core Infrastructure Services

| Infrastructure Component                 | AWS        | Microsoft Azure                 | Google Cloud Platform |
| ---------------------------------------- | ---------- | ------------------------------- | --------------------- |
| **Compute**                              | Amazon EC2 | Azure Virtual Machines          | Compute Engine        |
| **Storage**                              | Amazon S3  | Azure Blob Storage              | Cloud Storage         |
| **Networking**                           | Amazon VPC | Azure Virtual Network (VNet)    | Google Cloud VPC      |
| **Identity and Access Management (IAM)** | AWS IAM    | Microsoft Entra ID + Azure RBAC | Google Cloud IAM      |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

I would say **AWS** because it has a very large collection of cloud services covering computing, storage, databases, networking, security, AI, and many other areas. It also provides many different options for different types of workloads.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

I would recommend **Microsoft Azure** because it works well with Microsoft products and services. It also integrates with Microsoft Entra ID and other Microsoft technologies, making it easier for organizations already using the Microsoft ecosystem.

### 3. Which platform is widely recognized for AI, ML, and Kubernetes services?

**Google Cloud Platform (GCP)** is widely recognized for its AI and machine learning capabilities and its strong Kubernetes services. Google created Kubernetes, and GCP provides Google Kubernetes Engine (GKE) for running containerized applications.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer similar core services, including compute, storage, networking, and identity management. The main difference is the name and specific features of each service, but their basic purpose is very similar.
