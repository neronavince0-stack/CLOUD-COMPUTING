
# Mission Reflection

## 1. Most Important Cloud Infrastructure Component

For me, the **compute resource** is the most important cloud infrastructure component because it is responsible for processing tasks and running applications. Without compute resources, applications and services would not be able to perform their functions. However, compute also depends on storage, networking, and the operating system to work properly.

## 2. How Linux Supports Cloud Computing

Linux supports cloud computing by providing a stable and flexible operating system for servers. It is widely used because it is lightweight, reliable, and supports many cloud technologies. In this laboratory, I used Linux commands in KillerCoda to check the server's CPU, memory, storage, network, and operating system information.

## 3. Importance of Technical Documentation

Technical documentation is important because it helps engineers understand and manage an infrastructure before it is deployed. It provides a record of the system configuration, resources, and design decisions. Good documentation can also make troubleshooting easier and help other team members understand the infrastructure.
