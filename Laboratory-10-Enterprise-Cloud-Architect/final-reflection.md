# Final Reflection – Mission 10: The Enterprise Cloud Architect

Completing this CloudNova Private Cloud project helped me understand how enterprise cloud infrastructure works. Throughout this activity, I gained practical experience in setting up an Ubuntu Server virtual machine using VirtualBox and deploying Nextcloud with MariaDB through Docker Compose.

I also learned how to configure persistent storage using Docker volumes to keep application data. For security, I enabled UFW firewall and allowed only the necessary ports for SSH and Nextcloud access.

One of the most important parts of this activity was creating Bash automation scripts for database backups, Nextcloud file backups, and system health monitoring. I also used Cron to schedule these tasks automatically.

During the activity, I encountered challenges involving Docker Compose configuration, terminal commands, and automation scripts. By troubleshooting each problem step by step, I improved my Linux and Docker management skills.

Overall, this project taught me the importance of security, data persistence, automation, and proper system maintenance. As an IT student, this experience improved my understanding of cloud computing and gave me practical knowledge that I can apply to future IT projects.
